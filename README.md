# Anime Dungeon

Next.js anime-discovery frontend using server actions, animated cards, and infinite scrolling. It retrieves anime records through the server-side action and displays artwork, ratings, and episode information.

## Getting started

Run `npm ci`, then `npm run dev`, and open `http://localhost:3000/`. Use `npm run build` for a production build. The original JavaScript Mastery tutorial credits and links are retained below.
